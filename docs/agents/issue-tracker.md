# Issue tracker: GitHub

Issues and specs live in Shaderx/Orbfarmer GitHub Issues. Use the gh CLI inside this checkout, or pass --repo Shaderx/Orbfarmer explicitly.

Read a ticket with gh issue view <number> --comments. Create or update issues only when the user request or an explicitly invoked skill authorizes publication. For multiline bodies, write the text to a temporary file and use --body-file.

When a skill says to publish to the issue tracker, create a GitHub issue. When a skill says to fetch a ticket, read the issue and its comments.

PRs as a request surface: no.
