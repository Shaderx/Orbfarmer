# Triage labels

Use these exact label strings when a skill assigns a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | needs-triage | Maintainer must evaluate the issue. |
| Needs information | needs-info | Reporter must provide more information. |
| Ready for agent | ready-for-agent | Requirements are complete for autonomous work. |
| Ready for human | ready-for-human | A human must implement the work. |
| Will not fix | wontfix | Maintainer has declined the work. |
